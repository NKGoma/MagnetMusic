One-time setup needed

You need a free Spotify Developer Client ID (5 minutes):

  1. Go to developer.spotify.com — log in with your normal Spotify account.
  2. Click Create app. Name it anything (e.g. "Norster"). Check "Web API" under APIs used.
  3. Under Redirect URIs, paste exactly: then click Add.
  4. Save, then copy your Client ID from the app dashboard.
  5. Open index.html in a text editor, find YOUR_CLIENT_ID_HERE and paste your ID.
  6. Save and re-upload to GitHub Pages, then refresh this page.
